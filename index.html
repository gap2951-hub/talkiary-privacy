Talkiary 개인정보처리방침

시행일: 2026년 7월 20일 · 최종 수정일: 2026년 7월 24일

Talkiary(이하 “본 앱”)는 이용자가 AI와 음성으로 하루를 이야기하면 그 내용을 바탕으로 일기를 만들어 주는 안드로이드 애플리케이션입니다. 본 방침은 본 앱이 이용자의 정보를 어떻게 다루는지 설명합니다.

핵심 요약 — 본 앱은 별도의 서버를 운영하지 않습니다. 이용자의 일기·대화 기록·설정은 모두 이용자의 기기 안에만 저장되며, 개발자는 이를 수집하거나 열람할 수 없습니다. 본 앱은 광고, 분석 도구, 추적 기능을 일절 포함하지 않습니다. 다만 AI 대화 기능을 위해 이용자가 입력한 내용이 아래에 설명된 방식으로 Google 등 제3자 서비스로 전송됩니다.

1. 본 앱이 처리하는 정보

음성(마이크)

  • AI와 통화할 때 이용자의 음성을 마이크로 입력받아 텍스트로 변환하는 데 사용합니다.
  • 음성 변환은 기기의 시스템 음성인식 기능(대부분의 기기에서 Google 음성인식)을 통해 이루어집니다. 이 과정에서 오디오가 해당 음성인식 제공자의 서버로 전송되어 처리될 수 있습니다.
  • 본 앱은 녹음된 오디오 파일을 저장하지 않으며, 변환된 텍스트만 대화에 사용합니다.

대화 및 일기 내용

  • 이용자가 AI와 나눈 대화 텍스트, 대화 요약, AI가 생성한 일기, 감정 분류, 그리고 “장기 기억”·“말투 프로필” 등 대화 품질을 위해 앱이 정리한 정보가 포함됩니다.
  • 이 정보는 이용자의 기기 내부 데이터베이스에만 저장됩니다.
  • AI 응답과 일기를 생성하기 위해, 해당 대화 내용은 아래 3항의 Google Gemini로 전송됩니다.

AI 연결 키(이용자 본인의 API 키)

  • 본 앱의 AI 기능은 이용자가 직접 발급받은 Google Gemini API 키로 동작합니다.
  • 이 키는 Android Keystore로 암호화되어 이용자의 기기에만 저장되며, 개발자나 외부로 전송되지 않습니다.

기기 권한

권한사용 목적
마이크(RECORD_AUDIO)AI와의 음성 대화를 텍스트로 변환하기 위함
인터넷(INTERNET)AI 응답 생성 및 고품질 음성 모델 다운로드를 위함

2. 정보의 저장과 보안

  • 모든 일기·대화 기록·설정은 이용자 기기 내 로컬 저장소에만 보관됩니다. 개발자가 운영하는 서버는 존재하지 않습니다.
  • AI 연결 키는 Android Keystore 기반 암호화로 저장됩니다.
  • 본 앱은 이용자를 식별하기 위한 계정 생성, 로그인, 회원가입을 요구하지 않습니다.

3. 제3자 서비스

본 앱은 다음 제3자 서비스를 이용하며, 각 서비스로 전송되는 정보는 해당 서비스의 개인정보처리방침을 따릅니다.

서비스전송되는 정보 / 목적
Google Gemini API
(이용자 본인 키 사용)		 AI 응답·일기 생성을 위해 대화 텍스트가 전송됩니다. 이용자 본인의 API 키로 호출되므로 Google의 API 이용약관 및 개인정보처리방침이 적용됩니다.
기기 시스템 음성인식
(대부분 Google)		 음성을 텍스트로 변환하기 위해 오디오가 인식 제공자로 전송될 수 있습니다.
Hugging Face 이용자가 “고품질 AI 목소리(Supertonic)”를 선택해 모델을 다운로드할 때만 접속합니다. 파일 다운로드 용도이며, 이용자의 대화나 개인정보는 전송되지 않습니다.

참고: Google 개인정보처리방침 — https://policies.google.com/privacy

4. 정보의 보관 기간 및 삭제

  • 기기에 저장된 일기·대화 기록은 이용자가 삭제하기 전까지 보관되며, 앱 내에서 개별 삭제할 수 있습니다.
  • 본 앱을 삭제(제거)하면 기기에 저장된 모든 데이터와 AI 연결 키가 함께 삭제됩니다.
  • 이용자가 “데이터 백업” 기능으로 만든 백업 파일은 이용자가 선택한 위치에 저장되며, 그 관리 책임은 이용자에게 있습니다.

5. AI 생성 콘텐츠와 신고

본 앱의 대화 응답과 일기는 생성형 AI(Google Gemini)가 만들어 냅니다. AI는 부정확하거나 부적절한 내용을 생성할 수 있으므로, 이용자는 앱 안에서 언제든지 해당 결과를 신고할 수 있습니다.

신고 방법

  • AI 대화 응답 — 통화 화면에서 해당 메시지를 길게 눌러 “AI 응답 신고”를 선택합니다.
  • AI가 생성한 일기 — 일기 상세 화면의 공유 메뉴에서 “AI 생성 내용 신고”를 선택합니다.
  • 그 밖의 문제 — 프로필 화면의 “문제 신고 · 문의”를 이용하거나, 아래 문의처 이메일로 직접 보내주셔도 됩니다.
신고는 이용자의 메일 앱을 통해 전송됩니다. 개발자가 운영하는 신고 접수 서버는 존재하지 않으며, 이용자가 직접 보내기를 누르기 전까지 어떤 정보도 전송되지 않습니다. 메일 본문에는 신고 사유, 신고 대상이 된 내용, 앱 버전, 기기 모델명과 안드로이드 버전이 자동으로 작성되며, 이용자는 보내기 전에 원하지 않는 부분을 직접 지우거나 수정할 수 있습니다.

접수된 신고 내용은 문제 확인과 앱 개선 목적으로만 이용하며, 처리 후 지체 없이 파기합니다. 다른 목적으로 이용하거나 제3자에게 제공하지 않습니다.
